Gamma & Delta Exposure analytics

An open-source dashboard for reading SPX, NDX, SPY and QQQ options structure — gamma walls, Gamma Flip, HVL, delta flow — built on CBOE's free public data. No account, no subscription.

MIT License Python · Dash 15-min delayed data Analysis only — no execution

Getting started

Python 3.11 or newer, and Git. About two minutes.

Install and run

🔰 Never installed something like this? Follow the step-by-step beginner guide — no knowledge required, ~15 min. The commands below are the quick summary for users already comfortable with a terminal.

git clone https://github.com/Darthreign/gex-dashboard.git
cd gex-dashboard
python -m venv .venv

Then, depending on your system:

.venv\Scripts\pip install -r requirements.txt      # Windows
.venv/bin/pip install -r requirements.txt          # macOS / Linux

Run it:

.venv\Scripts\python run.py       # Windows
.venv/bin/python run.py           # macOS / Linux

Open http://127.0.0.1:9050. No configuration needed: collection starts immediately, and the interface follows your browser language.

Does it need to run all the time?

No, with one nuance. The levels (GEX, walls, Gamma Flip, HVL) are snapshots of the current state: they rebuild completely on the first refresh, no matter how long it was off.

The intraday delta flow, however, is measured between two polls: it can only be captured while running during the session. In practice, start it before the US open on days you're trading.

Does my data stay on my machine?

Entirely. Everything is stored locally (Parquet format) and the dashboard only listens on 127.0.0.1, i.e. your own machine. Nothing is sent anywhere.

The data

Where does it come from?

From CBOE's public delayed endpoint — CBOE operates the US options markets: full SPX and NDX chains with bid/ask, implied volatility, open interest and volume. No account, no API key, no subscription.

Why a 15-minute delay?

That's the delay on the free public feed. Redistributing real-time data would require an expensive professional licence — but for personal use, a broker account is enough (see below).

But it matters far less than you'd think: the metric everything rests on — open interest — is published only once a day by the OCC. Gamma walls and the Gamma Flip derive from it and barely move intraday. The delay only really affects the reference price and the intraday flow.

Why can't I use your instance?

First because you don't need to: the CBOE source is free and account-free, so your instance shows exactly the same data.

Then for licensing: if an instance is enriched with optional data (paid history, real-time broker feed), that data is licensed for personal, non-redistributable use. Sharing it would be prohibited redistribution. Hence the principle: the code is shared, the data is not.

Index points or futures points?

Either, via the Index / ES (or NQ) toggle. This matters: the gap is around +30 points on ES and +150 on NQ — putting a raw SPX level on an ES chart would throw everything off. The basis is recomputed on every refresh from put-call parity and follows the quarterly roll automatically.

Can I display SPX levels on an NQ scale?

Yes — the Index / ES / NQ selector transposes all levels to the chosen scale, including across families (SPX to NQ, NDX to ES). Some traders cross these because market makers don't always hedge on the direct underlying.

Two conversion modes: to the future of the same index, the basis is applied (exact conversion); otherwise it is proportional and preserves the relative distance to spot — a wall 1.2% above SPX spot shows 1.2% above the target spot.

Across families, the SPX/NDX ratio drifts continuously with relative performance: a transposed level is a point-in-time reference, not a stable level. The ratio used is displayed, and a warning accompanies this mode. Dollar amounts remain those of the source underlying — it is its gamma, merely repositioned.

Can I plot these levels on TradingView?

Yes. The copy button to the right of the levels strip puts every current level on the clipboard, in the format expected by the GEX Levels (Dealer Gamma Exposure) indicator. Add it to your chart, open its settings, and paste the string into the zone matching your market (NQ, ES or SPX).

The string follows the selected scale: if you are viewing ES, the levels are already converted to ES points. So pick the scale of the chart you will paste onto, otherwise the lines land off by the basis.

The format is price,label,kind separated by semicolons. Two mappings are worth knowing: HVL is sent as kind flip (it is one, weighted by the session's volume rather than open interest), and 1D Min/Max go out as eml/emh — they are indeed the expected-move bounds.

A GEX wall that coincides with a named level is not sent twice: Call Wall and Put Support come from the same strike ranking as GEX1-5, and the flip often lands on a wall. Only the more meaningful label is kept — the line is still drawn, we just avoid two overlapping labels.

Levels do not refresh by themselves on TradingView: the string is a snapshot. Since walls and the flip rest on open interest, published once a day, pasting at the open holds for the session — re-copy after a sharp move if you want it fresh. The same string is the workaround on any platform that blocks outbound network calls (Tradovate, for one).

Going real-time (optional)

What becomes real-time, and what stays delayed?

The distinction matters: only prices go live, not the option chains. Those still come from CBOE with a 15-minute delay.

What real time actually buys you: the spot of underlyings and futures, net GEX recomputed at that spot — hence the distance to the Gamma Flip and the regime read, which go stale within minutes — a 1-minute bar recording, and several weeks of history retrievable in one pass.

What it does not buy you: gamma walls and the Gamma Flip do not move any more for it. They rest on open interest, published once a day — refreshing them faster would be meaningless.

How do I enable it?

The real-time feed comes from dxFeed, reached through a broker account — the dashboard is written for tastytrade, which includes this data at no extra cost. Opening a brokerage account is a personal and consequential step; the dashboard works perfectly without one, and nothing here is a recommendation to open one.

Once the account exists, setup is three steps:

  1. Create an OAuth application from the account settings, which yields a client id and secret.
  2. Run python -m gex.tt_auth: it prints a URL to open, you approve in your browser, and it derives a refresh token.
  3. Put TASTYTRADE_CLIENT_ID, TASTYTRADE_CLIENT_SECRET and TT_REFRESH into environment variables.

Those three values are credentials to a brokerage account: they do not belong in a repository file, a screenshot, or a conversation. Environment variables, nowhere else.

On the next start, a dxFeed badge appears at the top right — green while the feed holds, amber if it lags, red if it drops. Without credentials it stays hidden and nothing changes.

Can I share that data?

No. Broker quotes are licensed for personal use: you may display and store them locally, not redistribute them. That includes a private repository shared with anyone but yourself.

The program enforces this by construction. Bars land in data/prices/ with provenance stamped at write time, and the export function only lets CBOE-sourced data through — everything else is excluded by default, including any source added later.

A consequence to accept: if you share your instance with friends, theirs stays delayed. The code is shareable, the data is not.

The levels

GEX · Gamma Exposure

An estimate of the gamma market makers must hedge, in dollars per 1% move.

  • Positive net GEX → stabilizing regime: dealers sell strength and buy weakness, volatility is dampened.
  • Negative net GEX → destabilizing regime: they do the opposite and amplify moves.
Gamma Flip

The level where net GEX changes sign — the boundary between the two regimes. It isn't read off the chart: the full profile is recomputed across a grid of hypothetical prices, then the crossing is interpolated.

HVL · High Volatility Level

Same computation as the Gamma Flip, but weighted by today's volume instead of open interest. The Flip describes inherited structure, the HVL reflects what is actually trading — and being hedged — today. A wide gap between them is itself information.

Call Wall · Put Support

The largest gamma concentrations, directionally constrained: the Call Wall is the largest call wall above price (resistance), the Put Support the largest put wall below (support).

That constraint isn't cosmetic: the largest put wall in absolute terms can sit above price, in which case calling it "support" would be meaningless.

1D Min · 1D Max

Expected move boundaries for the nearest expiration, derived from the at-the-money straddle price. The straddle is the market's own estimate — no model assumption involved.

GEX1 to GEX5, DEX

GEX1-5: the five strikes with the largest absolute gamma, with no directional constraint — the raw walls, ranked by weight.

DEX: the delta equivalent of GEX — the directional exposure carried at each strike.

Vanna · Charm

Vanna — sensitivity of delta to implied volatility. When IV compresses, dealers must buy back delta: the mechanism behind slow grinds higher with no obvious catalyst.

Charm — decay of delta as time passes. This flow is purely mechanical and therefore predictable; it explains part of end-of-day drifts and expiration-week behaviour.

The delta flow — and its limit

An estimate of delta traded minute by minute, from each contract's volume change multiplied by its delta.

The free feed doesn't say whether a trade was buyer- or seller-initiated. So this measures delta-weighted pressure, not true signed order flow: it shows intensity and concentration, not aggressive direction.

Sharing the verdict (Discord bot)

Broadcast your conclusion to friends, without giving them the data.

Share my analysis without sharing the data?

That's what the Discord bot in discord_bot/ is for. It relays the gamma-state verdict into a channel — the conclusion, not the data. Friends see "Negative gamma on the Nasdaq, contrarian trading risky" without a broker account or access to the option chains.

The bot only queries the local API (/api/v1/digest), which returns derived analysis only: signs, verdict, color, aggregate charts. Never the raw per-contract feed — that's what makes sharing compatible with a personally-licensed feed.

How is the verdict color decided?

Not by counting symbols equally: SPX/SPY/ES are three views of the same S&P 500, NDX/QQQ/NQ of the same Nasdaq. The verdict reasons by independent family, each aggregating its symbols' intensity with weights cash index > ETF > future. The cash index (SPX, NDX) is primary: if it turns strongly negative, its family does.

  • 🔴 Red: both families negative, or one strongly negative.
  • 🟠 Orange: one family negative, or VIX above the threshold.
  • 🟢 Green: otherwise.

A confidence line (high / medium / low) reflects data coverage. On-demand commands: !help, !etat, !gamma NQ, !niveaux NDX NQ (transposed levels), and any chart as an image (!heatmap NQ, !delta SPX…).

Known limitations

Stated plainly — better to know them before relying on any of this.

What the tool cannot do
  • 15-minute delay on the free source. A structure-reading tool, never an execution tool.
  • Open interest is daily. No provider, free or paid, changes that: the OCC publishes it.
  • Trade direction is not observable in the free feed.
  • Dealer positioning assumption. Like every tool of this kind, the computation assumes dealers are long calls and short puts. A common and useful convention, not a measured fact.
  • The CBOE endpoint is not contractual: its format can change without notice.
